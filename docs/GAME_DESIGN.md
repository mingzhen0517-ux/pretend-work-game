# 《假装上班》游戏设计文档

- 版本：1.0（可玩 Web 原型）
- 类型：21 天城市叙事 RPG / 空档期模拟 / 卡牌日程 / 关系对话
- v1.1 受众扩展：**不是只有被裁的人**。被动通知、主动请假、项目空档、照护假、长期上班后的短休，都可以进入空档期。
- 平台：手机优先 Web H5，单机，无需账号
- 一句话：HR 说“从明天开始，你不用去公司上班了”。你没告诉任何人，接下来的 21 天照常出门。

---

## 1. 用户洞察与市场切口

### 1.1 洞察
- 20–50 岁工薪族不只有“被裁”一种处境：有人主动请假、裸辞、项目轮休、照护家人，也有人只是长期上班后想喘口气。
- 20–50 岁工薪族最普遍的恐惧，不是“没工作”，而是“被看见没在上班”。休息也需要理由。
- “从明天开始，你不用去公司上班了”比“你被裁了”更真实：它礼貌、模糊，留出了继续演戏的空间。有人收到通知，有人自己按下暂停。
- 体面是日常成本：工牌、通勤、朋友圈、家长群，都在要求“看起来正常”。
- 长期通勤把人生变成轨道。主角在这条线上往返 11 年，闭着眼都知道哪一站开门。
- 不用上班不是失败，是突然多出一段“不知道怎么用”的时间。

### 1.2 市场切口
市面上已有《离职模拟器》《裁员模拟器》等单场景作品，多是一次性选项测验或 AI 对话。本作不重复做“被裁那一刻”，也不把空档等同于“赶紧找工作”；它把 **暂停之后的 21 天** 做成可反复玩的系统：

- 假装上班的潜行压力（露馅值、家庭盘问、熟人目击）。
- 12 条“不用上班后可以做的事”路线。
- 9 个不同年龄/家庭/职业的主角。
- 关键对话代替战斗：不打赢对方，而是谈成/谈崩。
- 结局、周报、空档人格、第二人生清单，天然适合分享。

### 1.3 设计支柱
1. **体面是资源，不是笑话**：笑的是系统，不是具体的人。
2. **城市是第二办公室**：图书馆、咖啡店、公园、共享办公、商场、前公司、人才市场、夜市。
3. **每条路都有代价，没有标准答案**：12 条路线都能通向体面的结局，也都可能走窄。
4. **那句话由玩家说出口**：全篇不急着定义你发生了什么；你可以一直用“在上班”撑着，也可以在某个时刻说出“我在休息 / 我被裁了 / 我请了假”。
5. **冲突不是打赢，是谈成**：职场和家庭的对手不是怪物，真正的失败是谈崩、耐心耗尽、信息不足。
6. **一天很短，21 天很长**：单日 60–90 秒，整轮 15–25 分钟。
7. **笑完要有一点暖**：黑色幽默是入口，治愈是落点。

## 2. 核心循环

### 2.1 一天
| 阶段 | 玩家做什么 | 系统产出 |
| --- | --- | --- |
| 早晨 | 看账单倒计时、今日城市事件，选择“去哪上班” | 地点加成、风险、当天手牌 |
| 通勤 | 30% 概率触发 2 选 1 小事件 | 露馅、心气、情报 |
| 白天 | 6 点精力，从 4 张手牌打出 2–4 个行动 | 检定、连击、随机事件、小游戏、关键对话 |
| 傍晚 | 回家 / 说加班 / 见人 / 去夜市 | 信任、露馅、家庭盘问 |
| 夜里 | 结算、选奖励、刷手机、周报、存档 | 分享、次日预告 |

- 地点：市图书馆、街角咖啡、中央公园、共享办公、商场/影院、前公司商圈、人才市场；夜市是傍晚特殊地点。
- “今日人设”连击：同标签打 2 张触发加成；3 个不同标签触发“全面发展”。
- 单日结束有“再撑一天”与“生成今日报告”，强化“再来一天”。

### 2.2 三周
| 幕 | 天数 | 主题 | 关键事件 |
| --- | --- | --- | --- |
| 第一幕 | 1–7 | 照常出门 | HR 通知、纸箱、地铁肌肉记忆、第一次说谎、遇见老赵、第一笔账单 |
| 第二幕 | 8–14 | 第二人生 | 路线开启、第一次被看见、家庭盘问、第二笔账单、坦白选项 |
| 第三幕 | 15–21 | 纸包不住火 | 路线冲刺、家长会/医院、家庭会议、结局 |

### 2.3 为什么“上头”
- **三角压力**：现金、体面、露馅。任何一个见底都会改写剧情，但不会立刻 Game Over。
- **差一点**：检定失败仍给一半进度，只加露馅或掉心气，诱发“明天再来一次”。
- **身份感**：9 个主角、12 条路线、16 个结局、空档人格、24 项清单。
- **收集欲**：24 件“不用上班后可以做的事”、12 段通勤记忆、16 个结局。
- **社交比较**：每日同种子挑战、周报评分、朋友的内推底牌。

### 3.2 人物
- **老赵**：42 岁前同事，也在空档，在夜市摆摊。路线引路人。金句：“别急着找下家。你先想想，有没有哪一天是你自己安排的。”
- **老李**：楼下保安，最早看穿主角的人。负责温度和笑点：“今天又加班啊？”
- **王总**：前领导，诱惑与体面来源。
- **HR Vivian**：不脸谱化，她也在完成 KPI。
- **张鹏**：老同学，创业/炫富线，高风险机会。
- **Amy**：猎头，年龄歧视与“已读不回”。
- **苏敏/阿哲/老顾**：伴侣线，对应共同还贷、异地不确定、中年搭伙。
- **朵朵/小宇/林一舟父母/刘芳女儿**：家庭线。

### 3.3 序章（已压缩为 4 拍）
1. **那一天**：角色专属的暂停原因。被动通知：HR 说“从明天开始，你不用去公司上班了”；主动请假：你提交了休假/辞职申请；项目空档：工厂轮休/项目结束；照护假：你请了长假。
2. **你**：你没有告诉任何人。第二天 8:15，你照常出门。
3. **心里**：你给这段日子起了个名字：空档期。
4. **专属开场**：每人 1 拍，例如母亲问面试、孩子问“今天不用开会吗”、医院来电。

序章只保留必要信息；更多背景放在角色卡和第一天的生活里。

## 4. 系统设计

### 4.1 属性
| 属性 | 范围 | 作用 | 主要来源 |
| --- | --- | --- | --- |
| 现金 | 0–∞ | 账单、路线投入、结局评分 | 补偿、副业、工资、借款 |
| 精力 | 0–6/天 | 行动货币 | 睡眠回满；熬夜/跑单消耗；健康低降上限 |
| 露馅 | 0–100 | 潜行压力，30/60/85/100 触发事件 | 高风险地点、被熟人看见、谎话矛盾；伪装/陪伴降低 |
| 体面 | 0–100 | 关键对话中的示弱/请求；面试/家庭/社交检定 | 打扮、礼物、上岸；跑单、被拆穿、借钱降低 |
| 心气 | 0–100 | 抗挫、关键对话中的坚持/边界；0 触发“摆烂日” | 小胜利、运动、陪伴；失败、比较、催收降低 |
| 健康 | 0–100 | 精力上限；过低触发医院事件 | 休息、运动；熬夜、跑单、应酬消耗 |
| 信任 | 0–100，显示为“家里的灯” | 关键对话中的坦白；家庭盘问、结局 | 陪伴、坦白、礼物；谎言、失约、暴露降低 |
| 技能 | 专业/人情/野路子 0–5 | 检定、对话选项、路线门槛 | 学习、接活、社交 |

### 4.2 卡牌与检定
- 40 张行动卡：10 张起始、21 张通用、9 张角色专属；每 2 天 3 选 1，牌库上限 18，夜里可花 300 删 1 张。
- 标签：求职、学习、搞钱、内容、生意、人情、家庭、休息、伪装。
- 检定：`成功率 = clamp(15%, 95%, 35% + 技能×8% + 地点/卡牌加成 − 难度 + 准备)`；确认前显示百分比；每个检定可花 1 精力“稳一手”+15%，每天一次。
- 失败仍给一半进度，不产生空转。
- 今日人设连击：同标签 2 张触发加成；3 个不同标签触发“全面发展”。

### 4.3 露馅、那句话与真相
| 露馅 | 触发 | 玩家应对 |
| --- | --- | --- |
| 30 | 邻居问“今天没上班？” | 圆谎、买礼物、换地点 |
| 60 | 配偶发现消费记录 | 家庭盘问小游戏 |
| 85 | 孩子/父母直接问 | 高强度盘问，信任受损 |
| 100 | 当晚强制家庭会议 | 坦白或崩盘，不打断白天行动 |

- 全篇不把“被裁”当成唯一前提。4 个“承认时刻”里，玩家可以说出角色专属的那句话：被动角色可能是“我被裁了”，主动角色是“我请了假/我在休息”，照护角色是“我请了长假”。
- 命名时刻：D3 母亲电话、D10 老赵、D18 伴侣/孩子、D21 家庭会议。
- 委婉：体面 +5、露馅 +8、心气 −3；直接：心气 +8、信任 +5（对家人 +8）、体面 −5。
- 对伴侣/孩子/家庭会议直接说，触发“家人知情”（toldFamily）：露馅清零、信任 +15、获得“家人托底”卡；高风险地点受限，伪装大师线锁定。
- 对母亲（异地）/老赵/自己说，只记录“说出口”（saidTheWord），不关闭潜行。
- 一直不说：不惩罚，结局进入“没说出口”尾声；说出口：进入“说出口”尾声。

### 4.4 经济与账单
- 三笔硬支出在第 7/14/21 天，金额按角色不同。
- 付不起时四选一：最低还款（负债 +10%）、找老同学借（体面 −10）、跟家里开口（信任 −15）、卖东西（心气 −10）。
- 收入：跑单 300–800/天、摆摊 500–2,000、私活 1,000–3,000、内容爆款 0–5,000。
- 负债进入结局评分；现金低于 -2 万触发“崩盘”。
- 标准/剧情两档难度：剧情模式账单 −30%、露馅增长 −25%、关键对话戒备增长 −20%。

### 4.6 关键对话（替代话术战）
> 为什么不做战斗：职场和家庭的冲突，不是把对方打到 0 血；真正的失败是谈崩、耐心耗尽、信息不足。改成“关键对话”后，9 个角色、12 条路线、16 个结局共用一套关系系统。

- 所有高冲突场景都是 3–5 轮“对话局”，没有 HP、攻击、防御、手牌和伤害数字。
- 三个可见量：
  - **理解** 0–100：目标值。
  - **戒备** 0–100：满了就破裂。
  - **耐心** 5 格：每轮消耗，归零则结束。
- 四个动词：听、问、说、停。
  - 听：揭示隐藏诉求；理解 +5、戒备 −5、耐心 −1。
  - 问：挖事实；问得太直会戒备 +10。
  - 说：选立场——事实、共情、幽默、示弱/请求、坚持/边界。
  - 停：耐心 +1、戒备 +3。
- 属性解锁：专业→事实/数据；人情→共情/旧情；野路子→幽默/转移；体面→示弱/请求；心气→坚持/边界；信任→坦白。
- **底牌**：21 天收集的 16 张事实/物件，每场对话可打 1–2 张，理解 +10、戒备 −8。
- 结果三档：共识（理解≥80 且戒备<50）、缓和（理解≥50）、破裂（戒备=100 或耐心=0）。
- **没有掷骰**：结果由信息、选择和耐心决定，失败不是运气。
- 5 场主线关键对话：HR（补偿）、前领导（回捞/背调）、房东（宽限）、张鹏（入伙/借钱）、家庭会议（三方）。
- 12 场路线关键对话：面试终面、政审面谈、返聘谈判、甲方改稿、客户报价、城管交涉、铺面谈判、车队队长、供应商、父母、伴侣/孩子、学员。
- 家庭会议是特殊三方对话：伴侣、孩子、父母各有隐藏诉求，共享 7 格耐心；每次只能听一个人，任何一人戒备满就提前破裂。

### 4.7 五个小游戏

## 8. 技术方案

- 原生 HTML/CSS/JavaScript ES Modules；无运行时依赖；手机优先。
- 单一状态树 + 纯函数 reducer：`UI 事件 → dispatch → core 计算 → 新 state → render → autosave`。
- `src/core/` 不碰 DOM，可直接在 Node 中测试；`src/ui/` 渲染与输入；`src/data/` 内容数据化。
- 构建 esbuild（唯一 devDependency）→ 内联 CSS/JS → `dist/index.html` 与根目录 `假装上班.html`；无外部请求，`file://` 可玩。
- 存档：localStorage `pretendWork.save.v1` / `meta.v1` / `settings.v1`；阶段结束与行动结算自动保存；坏档回退。
- 分享 URL：`?ref=CODE`、`?seed=YYYY-MM-DD&persona=xxx`、`?utm_source=share`。
- 无服务端 API；唯一公共接口是分享 URL 与 `window.__PRETEND_WORK__` 调试只读状态。

## 9. 指标与路线图

### 9.1 指标假设
| 环节 | 指标 | 首版假设 |
| --- | --- | --- |
| 激活 | 打开→开始游戏 | >60% |
| 上手 | 完成第 1 天 | >80% |
| 留存 | 到达第 7 天 | >50% |
| 完成 | 到达任一结局 | >30% |
| 分享 | 结局/周报分享点击 | >25% |
| 裂变 | 邀请链接打开→开局 | >10% |

指标用于决定 P1 优先级，不作为上线承诺。

### 9.2 P1
- 二维码、回礼内推、工牌图鉴/结局收藏册、PWA 离线安装。
- 52 岁“退休倒计时”角色、更多事件与手机动态、角色专属命名台词。
- 服务端每日榜与邀请归因（需后端）。
- 语音/更多像素动画/更多小游戏变体。

### 9.3 风险
- 内容量大：9×12 共用骨架，先保证数量与可通，再补密度。
- 数值易崩：模拟不同策略，先调破产率/结局分布。
- 裂变依赖渠道：先做身份分享与每日挑战，P1 再做服务端归因。
- 微信/大陆发行：域名、ICP、分享策略是运营依赖。
- 名称/商标：`假装上班`/`空档期` 较通用，商业发行前需检索。
- 情绪安全：不做羞辱式失败；家庭会议是沟通不是打赢家人；标题页有内容提示与求助信息。
